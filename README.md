# Elicit Knowledge Demonstrator

This is a small React + TypeScript project built to demonstrate knowledge relevant to Elicit's front-end engineering role. It addresses the key technical questions outlined in the job listing:

---

## 📋 What's Covered

### 1. React Re-Renders
- `Counter.tsx`
- Demonstrates how a React component re-renders on state change.
- Includes console logs to visually show render cycles.

### 2. Flexbox vs Grid Layout
- `LayoutDemo.tsx`
- Shows example of `flexbox` (simple linear layouts) vs `grid` (complex two-dimensional layouts).

### 3. Web Workers
- `WorkerDemo.tsx`
- Uses a Web Worker to calculate prime numbers up to 10,000 without blocking the UI.
- Demonstrates offloading heavy tasks to keep the app responsive.

### 4. Tailwind Drop Shadow
- `TailwindCard.tsx`
- Simple card using TailwindCSS `shadow-2xl` class to create drop shadow.
